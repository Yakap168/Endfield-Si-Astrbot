# 祀 — persona 数据包

《明日方舟：终末地》角色**祀**（Si）的人格数据：事实卡、语气样本、禁用模式、
知识库与术语卡。按「能直接喂给 AstrBot / 任意 LLM」的粒度整理，不依赖本仓库的插件。

```
persona/
├── system_prompt.md        人格提示词（v0.9）
├── begin_dialogs.json      13 组开场对
├── corpus/
│   ├── facts.json          31 条事实卡，带出处与剧透等级
│   ├── style_examples.jsonl 46 条语气样本，逐条标出处
│   └── banned_patterns.json 28 条禁用模式
└── kb/
    ├── 00_身份与来历.md … 50_剧情节点.md   6 篇长文，分块带元数据头
    └── terms/             61 张术语卡 + 别名索引
```

## 数据来源

| 内容 | 来源 |
|---|---|
| 台词、剧情、无线电 | `555me/beyondGameData` 2026-10-27 快照，`tableCfg/DialogTextTable.json`、`RadioTable.json` |
| 角色档案、语音 | 同上 `CharacterTable`；与 Warfarin Wiki 交叉核对 |
| 术语 | 游戏内词典 `NarrativeNoteEntryTable`；中枢档案 `PrtsDocument` / `RichContentTable` |
| 岁家十二代理人 | 《明日方舟》本家设定，Arknights Wiki「Sui」条目 |

## 引文编号约定

带 `第 N 句` 的引用，指**祀在该任务台词中的第 N 句**，依据 `DialogTextTable` 中
`actorNameId = si`、按 `dlg_{任务}_{幕}_{句}` 排序后的顺序。任务码含义：

| 任务码 | 版本 | 类型 | 任务名 |
|---|---|---|---|
| `e11m1` | 1.5「长风破浪」 | 主线 | 长风破浪 |
| `e11m8` | 1.5 | 主线 | 余晖未却 |
| `e12m1` | 1.6「丹青渡」 | 主线 | 入丹青 |
| `e12m2` | 1.6「丹青渡」 | 主线 | 知兴衰 |
| `e12m3` | 1.6「丹青渡」 | 主线 | 见纵横 |
| `e12m4` | 1.6「丹青渡」 | 主线 | 洞我执 |
| `e12m5` | 1.6「丹青渡」 | 主线 | 着新墨 |
| `f1m36` | 活动 | 活动任务 | 开画大吉（含 `f1m36d1`–`d3`） |
| `sm2l10m1`–`m3` | 支线 | 支线 | 无终之恋 / 前缘再续 / 纪念日 |
| `map02_lv010_env` | — | 场景对话 | 地图 02-010 |

引用他人（非祀）的台词时，`citation` 只标到任务，并在文字里注明说话人。

## 剧透分级

- **S0** 公开信息，可直接回答
- **S1** 轻度剧透：1.5 主线、客栈支线、活动章节
- **S2** 重度剧透：十年前旧约、1.6 丹青渡的结局与身世、管理员的心魔

`kb/50_剧情节点.md` 是 S2 密集文件，默认不主动展开。检索时按块头部的
`[类别:… | 剧透:… | 来源:…]` 过滤。
