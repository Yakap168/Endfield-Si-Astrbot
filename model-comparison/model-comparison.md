# 同一人格，不同模型：输入 / 模型 / 输出对照

> 同一套 system prompt、同一组 few-shot、同一温度（0.8），只换模型。
> 目的不是评优劣，而是看**同一个角色在不同模型手里会变成什么语气**。
> 输出为 AI 生成内容，基于同人设定，不含游戏原文。

## 观察

| 模型 | 倾向 | 典型表现 |
|---|---|---|
| GLM-5.3-Flash | 完整、信息多、略慢（3–7s） | 会把身份、地点、态度一次说全，代价是句子偏长 |
| Qwen3.8-Flash | 快、自然、偶有超短句（1–4s） | 口语感最强；「搞莫子」这类口癖出现得最自然，个别时候太简 |
| Qwen3.8-Max | 强、端着、成本高 | 身份强调最完整，也最容易把话说满 |
| DeepSeek-V4.1-Flash | 平衡、快 | 拒绝干脆，但个性弱于 GLM / Qwen |

**怎么选：**

- 要稳定完整的人设 → GLM-5.3-Flash
- 要响应速度和口语感 → Qwen3.8-Flash
- 要强设定、不介意成本和延迟 → Qwen3.8-Max
- 要低成本兜底 → DeepSeek-V4.1-Flash

## 一次修正记录

最初这一行里，多个路由的回答都在说「程序」，而输入明明是「AI」。原因不是模型，是 few-shot 里放了一条以「程序」作答的示例，又在提示里写死了「程序？你们这边的说法真怪」这句纠正语，模型于是把「程序」当成了固定模板。

修正方式：

1. 删掉 few-shot 里那条「程序」示例
2. 提示词改成「对方用哪个词，你就把哪个词还回去」——问 AI 说 AI，问程序说程序

修正后各模型都稳定回「AI？那是什么东西。我是巨兽代理人。」

## 读表注意

- 每个格子只有一次采样，模型输出有随机性，不能当作严格评测
- 温度固定 0.8；降温会更稳，但也会更平
- 不同模型的「像」标准不同：有的靠内容完整，有的靠语气短促
- 这张表只覆盖语言风格，不覆盖事实准确性——事实要靠知识库与测试集单独验
