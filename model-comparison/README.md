# model-comparison

同一人格、同一提示词、同一温度，只换模型，看输出差在哪。

- 主表：三个高频问题 × 四个模型
- 副表：其他输入的单点对照
- 观察：每个模型的倾向与适用场景

文件：[model-comparison.md](model-comparison.md)

## 用途

1. 选模型时有一个直观参照，而不是只看价格和跑分
2. 调试人格时，判断「这句话不像她」是提示词的问题还是模型的问题
3. 给社区用户一个预期：同一套设定在不同模型上会长成什么样

## 说明

- 输出为 AI 生成内容，基于同人设定，不含游戏原文
- 每次只有一条样本，温度 0.8，不能当作严格评测
- 事实准确性不在本表范围内
